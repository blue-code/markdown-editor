Nebula Note 是一款简洁专注的 Mac Markdown 编辑器，实时预览会在您输入时即刻渲染图表和数学公式。

边写边看
• 带代码语法高亮和一键拷贝按钮的实时预览
• 支持表格、任务列表、目录、链接和图片
• 使用 MathJax 渲染 LaTeX 公式 ($E = mc^2$)

内置 Mermaid 图表
• 流程图、时序图、类图、状态图、ER 图、甘特图、饼图、思维导图、Git 图、用户旅程图、时间线、象限图、桑基图、XY 图表、框图、C4、看板等 19 种
• 专用图表查看器，支持缩放、适应窗口和全屏
• 可导出为 SVG、PNG 或高分辨率 PNG @2x

沉浸式写作
• 专注模式，只留下文字
• 文档大纲，快速在标题间跳转
• 按 Tab 展开的代码片段和 Markdown 自动补全
• 字数目标、阅读时间和详细的文档统计
• 支持正则表达式的查找和替换
• 一键格式化表格、排序行、删除空行

为 Mac 打造
• 深色模式和预览自定义 CSS
• 导出为独立 HTML 或 PDF
• 完全离线可用 — Mermaid 和 MathJax 已内置于应用
• 支持简体中文、英语、韩语和日语

您的文档不会离开您的 Mac。无需账户，没有跟踪。
