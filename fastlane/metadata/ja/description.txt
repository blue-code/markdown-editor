Nebula Note は、入力したそばから図や数式まで描画するリアルタイムプレビューを備えた、シンプルで集中できる Mac 用 Markdown エディタです。

書きながらすぐ確認
• コードのシンタックスハイライトとワンクリックのコピーボタン付きリアルタイムプレビュー
• 表、チェックリスト、目次、リンク、画像に対応
• MathJax による LaTeX 数式の表示 ($E = mc^2$)

Mermaid 図を標準搭載
• フローチャート、シーケンス図、クラス図、状態遷移図、ER 図、ガントチャート、円グラフ、マインドマップ、Git グラフ、ユーザージャーニー、タイムライン、4象限チャート、サンキー図、XY チャート、ブロック図、C4、カンバンなど 19 種類
• ズーム、ウィンドウに合わせる、フルスクリーンに対応した専用ビューア
• SVG、PNG、高解像度 PNG @2x で書き出し

集中して書くために
• 文章だけに集中できる集中モード
• 見出し間をすばやく移動できるアウトライン
• Tab キーで展開するスニペットと Markdown 入力補完
• 単語数の目標、読了時間、詳しい文書統計
• 正規表現対応の検索と置換
• 表の整形、行の並べ替え、空行の削除

Mac のために
• ダークモードとプレビュー用カスタム CSS
• 単体の HTML や PDF に書き出し
• 完全オフラインで動作 — Mermaid と MathJax をアプリに同梱
• 日本語、英語、韓国語、簡体字中国語に対応

書類が Mac の外に出ることはありません。アカウントもトラッキングもありません。
