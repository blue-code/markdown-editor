Nebula Note는 입력하는 즉시 다이어그램과 수식까지 그려주는 실시간 미리보기를 갖춘, 깔끔하고 집중하기 좋은 Mac용 마크다운 에디터입니다.

쓰면서 바로 확인
• 코드 하이라이트와 원클릭 복사 버튼이 있는 실시간 미리보기
• 표, 체크리스트, 목차, 링크와 이미지 지원
• MathJax로 렌더링되는 LaTeX 수식 ($E = mc^2$)

Mermaid 다이어그램 기본 내장
• 플로우차트, 시퀀스, 클래스, 상태, ER, 간트, 파이, 마인드맵, Git 그래프, 사용자 여정, 타임라인, 사분면, 생키, XY 차트, 블록, C4, 칸반 등 19종
• 확대/축소, 화면 맞춤, 전체 화면을 지원하는 전용 다이어그램 뷰어
• SVG, PNG, 고해상도 PNG @2x로 내보내기

몰입해서 글쓰기
• 글에만 집중할 수 있는 포커스 모드
• 제목 사이를 빠르게 이동하는 문서 개요
• Tab으로 확장되는 스니펫과 마크다운 자동완성
• 단어 목표, 읽기 시간, 상세한 문서 통계
• 정규식을 지원하는 찾기/바꾸기
• 표 자동 정렬, 줄 정렬, 빈 줄 제거

Mac에 맞춘 경험
• 다크 모드와 미리보기용 커스텀 CSS
• 독립 실행형 HTML 또는 PDF로 내보내기
• 완전한 오프라인 동작 — Mermaid와 MathJax가 앱에 포함
• 한국어, 영어, 일본어, 중국어(간체) 지원

문서는 Mac 밖으로 나가지 않습니다. 계정도, 추적도 없습니다.
